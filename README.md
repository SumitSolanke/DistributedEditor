# 🚀 Decentralized Collaborative Code Editor with Automated Version Control

A decentralized, local-first collaborative code editor that enables multiple developers to work together without relying on a centralized server. The application integrates real-time collaboration with automated Git-based version control, providing a seamless development experience while maintaining complete ownership of project data.

> 📖 **Research Paper Published in IEEE Xplore**
> **DOI:** `10.1109/CCGE67142.2026.11581829`

---

## 📌 Overview

Traditional collaborative code editors typically depend on centralized cloud infrastructure to synchronize files and manage version control. This project explores a decentralized alternative where collaborators can work directly with each other while preserving project history through automated Git operations.

The application is designed as a local-first desktop environment, allowing developers to collaborate, synchronize projects, manage branches, and perform version control operations from a unified interface.

## 🏗️ System Architecture

The application follows a modular architecture consisting of:

* **Frontend Layer** – Interactive desktop interface built with React and TypeScript.
* **Editor Layer** – Monaco Editor integration for an IDE-like coding experience.
* **Synchronization Layer** – Handles peer communication and project synchronization.
* **Version Control Layer** – Automates Git operations and repository management.
* **Storage Layer** – Manages local project metadata and application settings.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/SumitSolanke/DistributedEditor.git
```

### Frontend

```bash
cd distributed-editor
npm install
npm run dev
```

### Backend (Electron)

```bash
cd backend
npm install
npm start
```
